# CounterPick — MLBB Draft Intelligence

A lightweight, web-based draft assistant and counter-pick lookup tool for Mobile Legends: Bang Bang (MLBB).

## Features
- **Draft Assistant:** Input enemy team compositions to get real-time counter-pick recommendations based on win rate statistics.
- **Hero Lookup:** Search any hero to inspect their direct counters and optimal matchups.
- **Meta Tier List:** View the patch meta tier list.

## Credits & Data Sources
- **Matchup Statistics & Hero Data:** Fetched from the official [Mobile Legends: Bang Bang Site](https://www.mobilelegends.com).
- **Meta Tier List:** Curated by [u/hmmsucks](https://www.reddit.com/user/hmmsucks/) on Reddit.
